# Cutter reference

This is a manual reference, not a tool library or a source of automatically
validated cutting parameters.

## SPM200-2ES-1/8

The operator identified this as a SHARPRO flat end mill with two flutes and a
1/8-inch (3.175 mm) cutting diameter, and confirmed that it is center-cutting
and can plunge vertically.

The shank diameter, cutting length, overall length, coating, flute direction,
and material-specific feeds, speeds, and stepdowns have not been verified.
Confirm them from the cutter's packaging or an exact-model datasheet before
planning a cut; do not infer them from similarly named tools.
